# Requirements: Butter Homepage

## V1 Requirements

### Page frame and hero

- [ ] **FRAME-01**: Visitors can use the fixed homepage navigation, including a skip-to-content link, primary links, the Product dropdown, and a usable mobile navigation.
- [ ] **HERO-01**: Visitors see the specified hero headline, supporting copy, and Get Started action; the keychain presentation uses the checked-in hero/model assets where supported and a usable static fallback on mobile, reduced-motion, or WebGL failure.
- [ ] **MEDIA-01**: Homepage media is served from matching checked-in `public/` assets where available, without broken paths or runtime dependency on third-party media hosts. Missing source-export assets are recorded as unavailable rather than fabricated.

### Narrative and storytelling

- [ ] **TICK-01**: Visitors see the brand-proof ticker with the available local logos in a seamless horizontal loop that remains usable with reduced motion.
- [ ] **STORY-01**: Visitors see the statement section's text and media blocks move between the inline statement and timeline composition as they scroll.
- [ ] **STORY-02**: Visitors can explore the Inflate, Glow, Focus, and Halftone showcase cards and their documented or visually tuned hover treatments.
- [ ] **STORY-03**: Visitors can view the customizable-editor story and its local dial/slider and video previews in a responsive composition.
- [ ] **MOTION-01**: Visitors experience smooth scrolling synchronized with scroll-triggered reveals and section motion; documented timing/easing values are used where available and unspecified values remain tune-by-eye.

### Product workflow

- [ ] **PROD-01**: Visitors can scroll through the pinned/sticky Toolkit story and see its local library preview.
- [ ] **PROD-02**: Visitors can progress through Import, Edit, Enhance, and Ship in the pinned feature section, with the matching preview and progress behavior.
- [ ] **PROD-03**: Visitors can select Remix, Describe, or Code in the Create in 3 ways accordion and see the corresponding content/media preview.

### Discovery and page completion

- [ ] **DISC-01**: Visitors can browse the eight template examples in a draggable, looping carousel that supports touch and remains usable without motion.
- [ ] **DISC-02**: Visitors can view the Create more, faster and Turn anything into everything sections with their matching local media.
- [ ] **DISC-03**: Visitors can browse the Get the look examples in the documented pinned horizontal layout on larger screens and an accessible responsive layout on smaller screens.
- [ ] **FRAME-02**: Visitors can reach a complete, usable footer with its navigation, social, resource, and legal groups.
- [ ] **PAGE-01**: Visitors can scroll the complete corrected 15-block homepage in the order documented by the migration layout, from intro overlay through footer.
- [ ] **A11Y-01**: Visitors can use the page at 375px, 768px, and 1440px; reduced-motion users receive non-animated alternatives; and videos are muted, inline, initially not preloaded, and played only while in view.
- [ ] **QUAL-01**: The completed app passes `pnpm build` without TypeScript/build errors or browser-console errors, and mobile Lighthouse performance reaches at least 80.
