# Plan 05-01: AWS CDK Deployment Pipeline, Environment Exporter & Live Seeding

## Goal
Deploy the complete 6-stack SaafSafari serverless backend infrastructure to AWS `ap-south-1` (Mumbai), generate consistent environment variable files across the monorepo via an automated exporter script (`scripts/export-env.ts`), and populate the deployed `SaafSafariMain` DynamoDB table with the 158-item Delhi NCR territory and merchant seed dataset.

## User Decisions Honored
- **DEC-11 (Backend-First Development Sequence):** Backend infrastructure and data persistence must be 100% operational on live AWS before frontend development begins.
- **DEC-01 (Strict Delhi NCR Bounding Box):** Territories (68 H3 res-7 cells) and QR sources (40 locations) are seeded strictly within the National Capital Region.
- **DEC-03 (Single-Table DynamoDB Architecture):** All entities seeded into `SaafSafariMain` with single-table partition/sort key conventions and inverted GSI projections.
- **CON-01 (Zero Hardcoded Secrets):** Environment configurations dynamically generated from CloudFormation stack outputs.
