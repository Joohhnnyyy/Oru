# Plan 05-02: Automated End-to-End Live Integration Test Suite

## Goal
Implement and execute a comprehensive automated integration test suite against the deployed AWS `ap-south-1` infrastructure. The suite programmatically manages ephemeral Cognito users, executes live HTTP requests across all 19 API Gateway endpoints, validates atomic DynamoDB transactions and ledger records, exercises S3 presigned uploads and Step Functions multimodal AI verification, and produces a formal Milestone 1 sign-off report.

## User Decisions Honored
- **DEC-11 (Backend-First Development Sequence):** Every backend endpoint and async workflow must be validated against live AWS resources before frontend codebases are initialized.
- **DEC-03 (Single-Table DynamoDB & TransactWriteItems):** Validate atomic ledger creation, wallet balances, and territory health updates in `SaafSafariMain`.
- **DEC-07 (Multimodal AI Pipeline):** Verify Step Functions execution calling Amazon Rekognition and Bedrock Nova Lite (`amazon.nova-lite-v1:0`).
- **DEC-09 (Cedar Municipal Tenancy):** Verify that admin endpoints enforce Cedar authorization policies for `ward_admin` role and ward scope.
- **CON-01 (Ephemeral Test Security):** Zero hardcoded credentials; test users are programmatically provisioned and deleted via AWS SDK.
