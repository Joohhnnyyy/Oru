# Phase 7 Plan 03: Collector Mobile Mode: Rotating TOTP QR Engine, GPS Location Sharing, Collector Shift Metrics & Android Packaging

**Phase:** 7 (Mobile Application: Citizen & Collector Modes)  
**Plan:** 03 of 03  
**Requirements:** `QR-02`, `COL-01`, `COL-02`, `TRK-01`  
**Dependencies:** Plan 07-01 (Auth & App Shell), Plan 07-02 (Citizen Mode)

---

## 1. Goal

Implement the dedicated **Collector Mobile Mode** (role `collector`) per `SITEMAP-WEB-AND-MOBILE.md` (B7) designed specifically for informal waste workers and MCD truck drivers:
1. High-contrast, single-hand friendly UI with Hindi-first support.
2. Real-time 30-second rotating HMAC-SHA256 TOTP QR code engine with animated countdown progress ring.
3. Live GPS route broadcasting to Amazon Location Service tracker (`POST /v1/trucks/telemetry`).
4. Daily shift metrics (citizen scans completed, collector credits earned).
5. Seamless role toggle between Citizen and Collector modes.
6. EAS Build and Android standalone packaging configuration.

---

## 2. Tasks & Implementation Steps

### Task 1: Rotating TOTP QR Code Generation Engine (`QR-02`, `COL-01`)
- Build `src/utils/totp.ts`:
  - HMAC-SHA256 token generator synchronized with 30-second time steps matching backend `services/api/src/handlers/scans/verifyScan.ts`.
  - Formats QR payload: `saafsafari://collector?sourceId={sourceId}&token={totp}&ts={timestamp}&sig={signature}`.
  - Generates scannable QR code SVG with auto-refresh every 25–30 seconds.

### Task 2: Collector Home Screen (B7.1)
- Build `src/screens/collector/CollectorHomeScreen.tsx`:
  - High-contrast card with large typography and Hindi labels ("कचरा संग्रह क्यूआर" / "Waste Collection QR").
  - Large rotating QR code occupying ~70% screen width.
  - Circular animated SVG countdown ring showing remaining seconds (30s down to 0).
  - Linked source metadata badge (e.g. `MCD Truck DL-1M-4821` / `Ramu Kabadiwala Cart 12`).
  - **Today's Shift Stats**: Citizen scans verified today, collector credits earned (+10 GC per citizen handover).
  - **On-Route Toggle**: Start / End Shift button with green status pulse.

### Task 3: Live GPS Telemetry Broadcasting (`COL-02`, `TRK-01`)
- Build `src/services/telemetry.ts`:
  - Background/foreground location tracking service using `expo-location`.
  - Transmits location updates every 15–30 seconds to backend `POST /v1/trucks/telemetry` when "On Route" is active.
  - Updates Amazon Location Tracker device position so citizens can track incoming trucks in real time.
- Build `src/screens/collector/RouteStatusScreen.tsx` (B7.2):
  - Displays GPS connection quality, coordinates, last transmitted timestamp, and route breadcrumbs.

### Task 4: Collector Earnings & Shift History (B7.3, B7.4)
- Build `src/screens/collector/CollectorEarningsScreen.tsx`:
  - Shift ledger showing completed household handovers and weekly credit earnings.
- Build `src/screens/collector/CollectorSettingsScreen.tsx`:
  - Language switcher (Hindi / English).
  - One-tap "Switch to Citizen Mode" button allowing collectors to redeem their earned credits as citizens.

### Task 5: Mobile App Build, EAS Config & Verification
- Configure `apps/mobile/eas.json` for Android APK build profiles:
  - Preview APK configuration for direct sideloading and judge distribution.
- Test complete end-to-end bi-modal flow:
  1. Open Collector Mode as Rajesh Kumar on Truck DL1M-4821.
  2. Observe rotating QR code refresh every 30 seconds with countdown ring.
  3. Switch to Citizen Mode as Aarav Sharma.
  4. Scan the collector's QR code.
  5. Verify citizen receives credits (+30 GC with streak multiplier) and collector shift ledger records +10 GC.
