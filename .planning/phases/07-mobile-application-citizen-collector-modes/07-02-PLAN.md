# Phase 7 Plan 02: Citizen Mobile Experience: Home Hero, Interactive Map, Camera Scanner, Task Board, Wallet & Coupons

**Phase:** 7 (Mobile Application: Citizen & Collector Modes)  
**Plan:** 02 of 03  
**Requirements:** `MAP-01`, `TRK-01`, `QR-01`, `TASK-01`, `WALT-01`, `WALT-02`  
**Dependencies:** Plan 07-01 (App Shell, Navigators, Auth & API Client)

---

## 1. Goal

Implement the complete Citizen operational experience across all 5 bottom tabs in `apps/mobile`:
1. **Home Screen** (B2): Territory mascot hero, real-time health ring, streak indicator, daily tasks, live incoming truck card, and nearby drop points.
2. **Interactive Map Screen** (B3): Vector territory map with H3 polygons, live garbage truck markers, and interactive bottom sheets for territories and drop points.
3. **Scan Screen** (B4): Camera QR scanner with torch, proximity check, and animated credit award / error bottom sheets.
4. **Tasks Screen** (B5): Tabbed task board (Daily/Weekly/Monthly), task detail view, camera photo proof capture, and civic waste quiz flow.
5. **Profile Screen & Sub-Screens** (B6): Wallet with live ledger history, coupon marketplace with atomic redemption, active QR voucher wallet, and leaderboards.

---

## 2. Tasks & Implementation Steps

### Task 1: Tab 1 — Citizen Home Screen (B2)
- Build `src/screens/citizen/HomeScreen.tsx`:
  - **Territory Hero Card**: Displays mascot in current mood state (Sick / Recovering / Thriving / Legendary), territory name, animated circular health ring (0-100), and today's delta.
  - **Stats Strip**: Green Credit balance, lifetime XP progress bar with current level title, streak counter with flame icon.
  - **Today's Tasks**: Daily task list with instant action buttons (Scan / Photo / Check-in) and daily bonus tracker (e.g. 0/3 completed).
  - **Live Truck Nearby Card**: Live incoming vehicle chip showing distance, ETA, and quick scanner button.
  - **Nearby Drop Points**: Nearest smart bins, e-waste centers, and kabadiwala points with distance meters.
  - **Community Goal**: Monthly ward waste diversion progress bar.

### Task 2: Tab 2 — Interactive Territory Map (B3)
- Build `src/screens/citizen/MapScreen.tsx`:
  - Territory map showing H3 res-7 boundary polygons, color-coded by health state and mascot.
  - Live garbage truck pulsating markers (`TRK-01`) updated from `/v1/trucks/live`.
  - Floating controls: recenter, go to home territory, layer filter (Territories, Drop points, Trucks).
  - **Territory Detail Sheet**: Ward name, mascot stage, health trend, open tasks, and Explorer bonus multiplier.
  - **Drop Point Sheet**: Name, distance, accepted waste categories, and directions action.

### Task 3: Tab 3 — Camera QR Scanner & Award Sheets (B4)
- Build `src/screens/citizen/ScanScreen.tsx`:
  - Camera view with QR viewfinder overlay and torch toggle.
  - GPS accuracy verification indicator (checks distance within 75m for static QR, 150m for rotating QR).
  - Handles barcode detection and calls `POST /v1/scans`.
  - **Scan Result Sheet**: Celebratory credit pop, itemized reward breakdown (base, verification weight, streak, Explorer bonus, total), territory health gain, and updated task progress.
  - **Scan Error Sheet**: Human-friendly error diagnosis (`COOLDOWN_ACTIVE`, `OUT_OF_RANGE`, `TOKEN_EXPIRED`, `DAILY_CAP_REACHED`).

### Task 4: Tab 4 — Tasks Board & Photo Proof Flow (B5)
- Build `src/screens/citizen/TasksScreen.tsx` & `TaskDetailScreen.tsx`:
  - Tabbed categories: Daily, Weekly, Monthly, and Hotspot Bounties.
  - Reset countdown timer and period completion bonus trackers.
  - Task cards showing tier badge (Easy / Medium / Hard), reward credits, and verification type.
- Build `src/screens/citizen/PhotoProofModal.tsx`:
  - Camera capture flow with rubric reminder.
  - Ghost overlay alignment guide for before/after cleanup tasks.
  - S3 upload via presigned URL (`POST /v1/submissions`) and submission status tracker.
- Build `src/screens/citizen/CivicQuizModal.tsx`:
  - 5-question waste segregation quiz with instant educational feedback and credit reward.

### Task 5: Tab 5 — Profile, Wallet, Coupons & Vouchers (B6)
- Build `src/screens/citizen/ProfileScreen.tsx`:
  - User details, rank title, total verified actions, longest streak, and navigation to wallet, vouchers, settings.
- Build `src/screens/citizen/WalletScreen.tsx`:
  - Live Green Credits balance, XP tier progression (Beej to Van Rakshak), and searchable ledger feed.
- Build `src/screens/citizen/CouponsScreen.tsx` & `VouchersScreen.tsx`:
  - Eco-merchant partner catalog with category filter (Kirana, Transport, Compost, Repair).
  - 1-click atomic redemption calling `POST /v1/coupons/redeem`.
  - Scannable QR voucher cards with copyable codes and expiration dates.
- Build `src/screens/citizen/LeaderboardsScreen.tsx`:
  - Territory health gain leaderboard and individual citizen XP rankings.

---

## 3. Verification & Criteria of Done

- All 5 tabs render without runtime errors on iOS and Android simulators / web preview.
- Camera scanner correctly reads mock and live QR codes, displays credit animation, and updates wallet balance.
- Coupon redemption executes atomically against the backend and renders in the active vouchers list.
- Task check-in increments user streak and updates the home screen hero status.
