# Plan 01-02: AWS CDK Infrastructure Stacks

## Goal
Implement the modular AWS CDK v2 infrastructure stacks (`AuthStack`, `DataStack`, `GeoStack`, `ApiStack`) and reusable `TsLambda` construct in `infra/`, configuring Amazon Cognito passwordless Email OTP, DynamoDB single-table schema, Amazon Location Service resources, and API Gateway HTTP API.

## User Decisions Honored
- **D-01:** Modular 4-stack layout (`AuthStack`, `DataStack`, `GeoStack`, `ApiStack`) with explicit props passing and SSM parameter references.
- **D-02:** Centralized `ts-lambda.ts` construct with Node.js 22 (arm64) and esbuild bundling.
- **D-03:** Native Cognito User Pool Email OTP (`USER_AUTH` flow) in Essentials tier with pre-created user groups.
- **D-10:** Amazon Location Service for maps, geofences, and tracking.
