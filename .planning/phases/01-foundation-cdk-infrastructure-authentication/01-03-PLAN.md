# Plan 01-03: User Authentication & Onboarding Handlers

## Goal
Implement and test the core user profile and onboarding Lambda handlers in `services/api/`, connecting Cognito JWT authorizer claims to single-table DynamoDB user records and automatically assigning H3 resolution-7 home territories using `h3-js`.

## User Decisions Honored
- **D-04:** Onboarding endpoint (`POST /v1/onboarding`) accepts language and coordinates, assigning home territory at Uber H3 resolution 7 (`latLngToCell`).
- **D-05:** Hybrid development testing with Vitest unit tests verifying handler behavior before cloud deployment.
- **CON-01:** Extract `userId` exclusively from `event.requestContext.authorizer.jwt.claims.sub` and return standard `{ error: { code, message } }` on failures.
