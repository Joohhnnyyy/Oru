# Phase 6 Plan 01: Web Foundation, Cognito Authentication, Navigation Shell, and Interactive MapLibre H3 Territory Map

**Phase:** 6 (Web Applications: Citizen Portal & Municipal Console)  
**Plan:** 01 of 03  
**Requirements:** `MAP-01`, `MAP-02`, `TRK-01`  
**Dependencies:** Phase 5 (Live Backend Deployed)

---

## 1. Goal

Scaffold the web application in `apps/web` with Vite, React 19, and Tailwind CSS. Implement an authenticated API client connected to live AWS API Gateway and Cognito, a demo persona switcher for instant citizen/admin evaluation, and an interactive MapLibre GL H3 territory map visualizing all 61 Delhi wards with animal mascots, health states, and live garbage truck tracking.

---

## 2. Tasks & Implementation Steps

### Task 1: Web Application Scaffold & Build Setup
- Configure `apps/web/package.json` with dependencies: `react`, `react-dom`, `vite`, `tailwindcss`, `postcss`, `autoprefixer`, `maplibre-gl`, `lucide-react`, `clsx`, `tailwind-merge`.
- Set up `vite.config.ts`, `tailwind.config.js` (with SaafSafari color palette: emerald, forest, amber, slate, glassmorphic panels), `postcss.config.js`, and `index.html` with Google Fonts (Inter, Outfit).
- Configure CSS design system tokens in `src/index.css`.

### Task 2: Authentication & Live API Gateway Client
- Build `src/services/api.ts`: Type-safe HTTP client targeting `https://dp029jx9uf.execute-api.ap-south-1.amazonaws.com` with automatic JWT bearer token injection and error handling.
- Build `src/context/AuthContext.tsx`:
  - Supports standard Cognito sign-in.
  - Includes **Demo Persona Switcher**:
    - **Citizen Persona (Aarav Sharma)**: Seed citizen in Ward MCD South 34 (420 GC, Van Rakshak tier).
    - **Municipal Admin Persona (Ward 34 Admin)**: Elevated `ward_admin` in Cognito with Cedar permissions.
  - Persists active token and user profile in `localStorage`.

### Task 3: Interactive MapLibre H3 Territory Map (`MAP-01`)
- Build `src/components/map/TerritoryMap.tsx`:
  - Integrates MapLibre GL with dark vector style centered on Delhi NCR (`28.6139, 77.2090`, zoom 11).
  - Converts `DELHI_TERRITORIES` into a GeoJSON FeatureCollection with polygon boundaries.
  - Colors territories dynamically by health/mood state:
    - Sick (<50): `#EF4444`
    - Recovering (50–74): `#F59E0B`
    - Thriving (75–89): `#10B981`
    - Legendary (90+): `#8B5CF6`
  - Adds interactive hover highlights and click selection.
  - Renders live waste collection truck markers (`TRK-01`) using truck data from `/v1/trucks/live`.

### Task 4: Territory Inspection Drawer (`MAP-02`)
- Build `src/components/map/TerritoryDrawer.tsx`:
  - Slides open upon clicking any territory polygon.
  - Displays:
    - Ward name, H3 cell index, and Clean Index rating.
    - Animated health meter (0–100) with color-coded mood badge (Sick, Recovering, Thriving, Legendary).
    - Active territorial mascot badge (Dolphin, Blackbuck, Nilgai, etc.) with mood stage description.
    - Active civic waste hotspots count and recent verified cleanup actions count.
    - Quick action button to view territory leaderboard or report a dumping hotspot.

### Task 5: Citizen Portal Navigation Shell
- Build `src/components/layout/Header.tsx` and `src/components/layout/Navigation.tsx`:
  - Glassmorphic top navigation with SaafSafari branding, Green Credit live balance counter, streak indicator, and persona switch dropdown.
  - Tab navigation: **Map**, **Tasks**, **Wallet & Rewards**, **Leaderboards**, and **Municipal Console** (visible when in `ward_admin` role).

---

## 3. Verification Criteria

1. `apps/web` builds cleanly with `pnpm --filter @saafsafari/web build` without TypeScript or lint errors.
2. The web application renders in the browser, loads dark-mode MapLibre map centered on Delhi NCR, and visualizes all 61 H3 hexagonal wards.
3. Clicking any hexagon opens the territory drawer displaying correct health, mood, mascot, and ward metadata.
4. Toggling the persona switcher between Citizen and Municipal Admin updates user claims and active role seamlessly.
