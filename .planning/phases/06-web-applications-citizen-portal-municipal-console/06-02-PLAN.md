# Phase 6 Plan 02: Citizen Experience: Task Board, Wallet, Coupon Marketplace, and Leaderboards

**Phase:** 6 (Web Applications: Citizen Portal & Municipal Console)  
**Plan:** 02 of 03  
**Requirements:** `WALT-01`, `WALT-02`, `LEAD-01`, `LEAD-02`, `TASK-01`, `TASK-02`  
**Dependencies:** Plan 06-01 (Foundation, Auth & Layout)

---

## 1. Goal

Implement the complete citizen user experience in `apps/web`: deterministic periodic task boards with daily habit check-in, Green Credits wallet dashboard with tier evolution progress, merchant coupon marketplace with atomic 1-click redemption and QR voucher generation, and competitive territory/citizen leaderboards.

---

## 2. Tasks & Implementation Steps

### Task 1: Deterministic Task Board (`TASK-01`, `TASK-02`)
- Build `src/components/tasks/TaskBoard.tsx`:
  - Fetches task board data via `GET /v1/tasks`.
  - Tabbed interface: **Daily Board** (3 tasks: habit, T1, T2), **Weekly Board** (3 tasks), and **Monthly Board** (2 tasks + 1 territory goal).
  - Task cards display target count progress (`currentCount / targetCount`), Green Credit reward badge (`+10 GC`), and XP gain (`+25 XP`).
  - **Daily Habit Check-in Card**:
    - One-click check-in button calling live `POST /v1/tasks/checkin`.
    - Animates confetti / streak celebration upon completion and disables for the remainder of the calendar day.

### Task 2: Green Credits Wallet Dashboard (`WALT-01`)
- Build `src/components/wallet/WalletView.tsx`:
  - Fetches wallet details via `GET /v1/wallet`.
  - **Hero Balance Card**:
    - Current Green Credit balance with glowing currency icon.
    - Lifetime XP and Tier title badge (Beej 🌱, Ankur 🌿, Paudha 🪴, Vriksh 🌳, Van Rakshak 🛡️).
    - Tier progress bar showing XP progress toward next evolutionary level.
  - **Transaction Ledger**:
    - Scrollable feed of historical actions (scans, habits, redemptions) with timestamp, territory tag, and credits earned/spent.

### Task 3: Eco-Merchant Coupon Marketplace & Atomic Redemption (`WALT-02`)
- Build `src/components/coupons/CouponMarketplace.tsx`:
  - Fetches coupon catalog via live `GET /v1/coupons`.
  - Category filters: All, Food & Beverage, Sustainable Fashion, Organic Groceries, Dairy.
  - Coupon cards featuring merchant logo/name, discount offer title, GC cost pill, and stock badge.
  - Disable redemption if user's balance < coupon cost.
- Build `src/components/coupons/RedemptionModal.tsx`:
  - Triggered on "Redeem Reward".
  - Calls `POST /v1/coupons/redeem` against live API Gateway.
  - Renders unique redemption voucher with:
    - Scannable merchant QR code (generated using `qrcode.react`).
    - Alphanumeric redemption code string for in-store checkout.
    - Expiration countdown and usage instructions.
  - Instantly refreshes wallet balance across the app.

### Task 4: Interactive Civic Leaderboards (`LEAD-01`, `LEAD-02`)
- Build `src/components/leaderboards/LeaderboardView.tsx`:
  - Fetches leaderboard rankings via `GET /v1/leaderboards`.
  - Dual-mode view:
    - **Territory Leaderboard**: 61 Delhi wards ranked by weekly health point gain, displaying mascot icon, ward name, and current health score.
    - **Citizen Leaderboard**: Top recyclers across Delhi ranked by XP and credits, highlighting the active user's standing.
  - Podium display for top 3 champions with gold/silver/bronze badges.

---

## 3. Verification Criteria

1. Navigating to the **Tasks** tab loads all daily, weekly, and monthly tasks from live API Gateway.
2. Clicking daily habit check-in sends `POST /v1/tasks/checkin`, awards Green Credits, and updates streak counter.
3. Navigating to the **Wallet** tab displays correct balance, tier title, and recent ledger entries.
4. Redeeming a coupon calls live `POST /v1/coupons/redeem`, displays the modal with QR code and alphanumeric voucher code, and decrements balance atomically.
5. Leaderboards render ranked territories and citizens with top 3 visual highlights.
