# Plan 04-01: S3 Presigned Uploads & Step Functions AI Verification Pipeline

## Goal
Implement the photo proof submission endpoint (`POST /v1/submissions`) generating presigned S3 upload URLs with coordinate validation (`AI-01`), and the Step Functions multimodal AI verification pipeline (`AI-02`, `AI-03`) orchestrating Amazon Rekognition content moderation, Amazon Bedrock Nova Lite vision reasoning, automated credit rewards for high-confidence proof, and task-token callback suspension for borderline submissions awaiting human review.

## User Decisions Honored
- **DEC-03:** Single-table DynamoDB layout persisting submission items (`SUBMISSION#<id>`) and atomic credit/XP distribution.
- **DEC-07:** Serverless vision verification combining Amazon Rekognition moderation/labels with Amazon Bedrock Nova Lite (`amazon.nova-lite-v1:0`).
- **DEC-11:** Backend-first development sequence: complete async state machine, AI evaluation handlers, and unit tests before frontend development starts.
- **CON-01:** Authenticated endpoints strictly read user ID from authorizer JWT claims.
