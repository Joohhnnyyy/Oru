# Plan 04-02: Civic Hotspot Reporting, Bounty Task Generation & Nightly EventBridge Scheduler

## Goal
Implement citizen illegal dumping hotspot reporting (`POST /v1/hotspots`, `GET /v1/hotspots`) with automatic territory health penalties and automated cleanup Bounty task generation (`HOT-01`, `HOT-02`). Implement the EventBridge Scheduler rule and Lambda handler executing nightly 3% territory health decay across Delhi NCR (`MAP-03`).

## User Decisions Honored
- **DEC-03:** Single-table DynamoDB layout persisting hotspots (`HOTSPOT#<id>`) and bounties (`BOUNTY#<id>`).
- **DEC-04:** Pure mathematical rules from `@saafsafari/game-rules` (`applyNightlyDecay`, `getMoodState`).
- **DEC-11:** Backend-first development sequence: complete backend event scheduler and hotspot APIs before client apps.
- **CON-01:** Authenticated endpoints verify citizen ID from authorizer JWT claims.
