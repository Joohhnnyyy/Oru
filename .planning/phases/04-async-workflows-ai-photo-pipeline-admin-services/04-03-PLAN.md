# Plan 04-03: Municipal Admin Console APIs with Cedar Authorization & Review Queue Resolution

## Goal
Implement the municipal administrative APIs with Cedar policy-based authorization (`DEC-09`): ward-level territory health overview and hotspot heatmap query (`ADM-01`), QR source creation and export management (`ADM-02`), and human-in-the-loop review queue resolution (`ADM-03`) that awards citizen credits and completes suspended Step Functions task tokens.

## User Decisions Honored
- **DEC-03:** Single-table DynamoDB layout persisting QR sources (`QR#<id>`) and updating submission statuses.
- **DEC-07:** Resumes suspended Step Functions executions via `SendTaskSuccessCommand` on human review approval.
- **DEC-09:** Cedar policy authorization enforcing `ward_admin` role validation and tenancy boundaries.
- **DEC-11:** Backend-first development sequence: deliver full municipal backend APIs before frontend console development.
- **CON-01:** Authenticated endpoints verify `ward_admin` group membership from JWT authorizer claims.
