# Plan 02-02: Delhi NCR Territory Classification & GeoJSON Pipeline

## Goal
Build the geospatial pipeline that covers Delhi NCR with 60+ Uber H3 resolution-7 neighborhood hexagonal cells, classifies each cell by dominant land cover into one of 5 regional animal mascots with mood states, and exports a MapLibre-ready GeoJSON FeatureCollection.

## User Decisions Honored
- **DEC-05:** Uber H3 resolution 7 hexagonal grid for Delhi NCR (~5.16 km² area per territory).
- **DEC-07:** Regional animal mascots (Nilgai, Blackbuck, Indian Peafowl, Rhesus Macaque, Golden Jackal) and 4 mood states (Sick, Recovering, Thriving, Legendary).
- **D-10:** MapLibre-compatible GeoJSON vector polygon boundaries for rendering on Amazon Location Service maps.
