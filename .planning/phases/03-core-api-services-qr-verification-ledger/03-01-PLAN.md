# Plan 03-01: Task Boards, Habit Check-In & Leaderboards API

## Goal
Implement and test the deterministic task board generation service (`GET /v1/tasks`), the daily habit check-in transaction (`POST /v1/tasks/checkin`) with atomic streak progression in DynamoDB, and the competitive territory & citywide leaderboards API (`GET /v1/leaderboards`).

## User Decisions Honored
- **DEC-03:** Single-table DynamoDB design with atomic `TransactWriteItems` and condition expressions.
- **DEC-04:** Pure computation logic (`generateDailyTaskBoard`, `generateWeeklyTaskBoard`, `generateMonthlyTaskBoard`, `getUserTier`) imported from `@saafsafari/game-rules`.
- **DEC-11:** Backend-first development sequence: complete schemas, handlers, and unit tests before frontend development.
- **CON-01:** Authenticated endpoints read user ID strictly from JWT claims (`event.requestContext.authorizer.jwt.claims.sub`).
