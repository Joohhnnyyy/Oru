# Plan 03-03: Wallet, Coupon Redemption, Live Truck Tracker & ApiStack Routing

## Goal
Implement the user wallet service (`GET /v1/wallet`), coupon catalog and atomic redemption engine (`GET /v1/coupons`, `POST /v1/coupons/redeem`) with conditional write limits, live collection truck tracker query (`GET /v1/trucks/live`), and complete AWS CDK HTTP API route mounting in `infra/lib/api-stack.ts` with appropriate DynamoDB and Amazon Location IAM permissions.

## User Decisions Honored
- **DEC-03:** Single-table DynamoDB design with atomic `TransactWriteItems` ensuring coupon redemptions atomically debit balance (`balanceGC >= costGC`), decrement stock (`stock > 0`), enforce weekly merchant limits, and record spend in the audit ledger.
- **DEC-04:** Pure calculations (`getUserTier`) imported from `@saafsafari/game-rules`.
- **DEC-11:** Backend-first development sequence: all REST endpoints implemented, mounted in CDK, and validated via automated tests before frontend development starts.
- **CON-01:** Authenticated endpoints read user ID strictly from authorizer JWT claims.
