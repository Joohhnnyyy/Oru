# Plan 03-02: QR Verification Engine & Atomic Mutation Ledger

## Goal
Implement the high-integrity dual-mode QR verification engine (`POST /v1/scans`) validating static signed QR codes on municipal dustbins/e-waste hubs ($\le 75\text{ m}$ geofence) and rotating dynamic HMAC-SHA256 tokens from waste collection vehicles ($\le 150\text{ m}$ live proximity, 30s TTL). Execute every verified scan via atomic DynamoDB `TransactWriteItems` updating user balance, immutable audit ledger, 4-hour anti-abuse cooldowns, territory health, and collector scan rewards (up to 200 GC daily).

## User Decisions Honored
- **DEC-03:** Single-table DynamoDB design with atomic `TransactWriteItems` guaranteeing ledger consistency.
- **DEC-04:** Reward calculations (`calculateRewards`, `applyActionHealthGain`, `getUserTier`) imported from `@saafsafari/game-rules`.
- **DEC-06:** Verification Trust Ladder (T1 for static bins, T2 for collector trucks/e-waste) with streak and urgency multipliers capped at 2.0x.
- **DEC-11:** Backend-first development sequence: complete all backend verification handlers with 100% test coverage before frontend development.
- **CON-01:** Authenticated user ID extracted strictly from authorizer JWT claims.
